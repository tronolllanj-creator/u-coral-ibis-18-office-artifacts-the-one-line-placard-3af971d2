The shipped placard: "Ceremonial stapler, forged iron & spring-steel, Late Levantine Bureaucracy; driven through 30 layers of royal tax parchment to appease river gods during drought."

## Run it
```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
